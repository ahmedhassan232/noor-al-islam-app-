# نور الإسلام — Noor Al-Islam

تطبيق إسلامي شامل مبني من الصفر: المصحف الكامل قراءةً بالرسم العثماني واستماعاً
بستة قرّاء مع مصادر احتياطية موثقة، ١٠٠ حديث موثق بمخارجه، أذكار حصن المسلم
بعدّادات تفاعلية، مواقيت صلاة محسوبة محلياً، بوصلة قبلة تفاعلية، وإذاعات قرآنية
مباشرة موثقة — بتصميم ليلي/نهاري فاخر ودعم كامل للعربية RTL.

## التقنيات

Next.js 16 (React 19) • TypeScript strict • Tailwind CSS 4 • Zustand • مكتبة
`adhan` للمواقيت • Capacitor لأندرويد • Vitest للاختبارات.

## المتطلبات

- Node.js 20 أو أحدث
- لأندرويد: Android Studio (Hedgehog+) مع JDK 17 وAndroid SDK 34

## أوامر التشغيل (Windows CMD / PowerShell)

```bat
:: تثبيت الاعتماديات
npm install

:: خادم التطوير
npm run dev

:: بناء الإنتاج للويب
npm run build

:: تشغيل نسخة الإنتاج
npm start

:: الاختبارات الآلية (٤٠ اختباراً)
npx vitest run

:: فحص الأنواع
npx tsc --noEmit
```

## إعداد أندرويد (Capacitor)

معرّف التطبيق: `com.noorislam.app` — الاسم: «نور الإسلام».

```bat
:: ١) بناء ملفات ثابتة في المجلد out
set CAP_EXPORT=1 && npm run build

:: ٢) إنشاء مشروع أندرويد (مرة واحدة فقط)
npx cap add android

:: ٣) مزامنة ملفات الويب
npx cap sync android

:: ٤) فتح أندرويد ستوديو ثم: Build > Build Bundle(s)/APK(s) > Build APK(s)
npx cap open android
```

> ملاحظة: لم يُبنَ APK داخل هذه البيئة لغياب Android SDK — الخطوات أعلاه موثقة
> ومضبوطة في `capacitor.config.ts` (webDir = out). الصوت والجغرافيا وحساس
> الاتجاه تعمل عبر واجهات الويب القياسية داخل Android WebView، وتتطلب الجغرافيا
> إذناً يُطلب عند الاستخدام فقط (فعّل «تحديد الدقة العالية» في إعدادات الجهاز).

## مصادر المحتوى (التوثيق)

| المحتوى | المصدر |
|---|---|
| نص القرآن | AlQuran Cloud — رواية حفص بالرسم العثماني (يُخزَّن محلياً بعد أول عرض) |
| التلاوات | Islamic Network CDN + احتياطي موثق من MP3Quran — تم التحقق برمجياً من كل رابط |
| الأحاديث | ١٠٠ حديث منقولة عن الطبعات المعتمدة (البخاري، مسلم، الترمذي، أبو داود، الأربعون النووية). الترقيم بحسب الترقيم الشائع وقد يختلف يسيراً بين الطبعات |
| الأذكار | حصن المسلم وكتب الأذكار الموثقة، والأدعية القرآنية من نص المصحف |
| المواقيت والقبلة | حساب فلكي محلي كامل (adhan + معادلات الدائرة العظمى) — لا بيانات وهمية |
| الإذاعة | محطات Qurango الرسمية عبر HTTPS — محققة الاستجابة |

## بنية المشروع

```
src/
  app/                  # الصفحات: الرئيسية، القرآن، [سورة]، الأحاديث، الأذكار،
                        # الصلاة، القبلة، الإذاعة، المفضلة، الإعدادات
  components/           # الهيكل، المشغّل المصغّر/الكامل، البحث الشامل، الزخارف
  lib/
    data/               # ١١٤ سورة + ١٠٠ حديث + الأذكار + القرّاء والمحطات
    services/           # محرّك الصوت، نص القرآن (تخزين مؤقت)، المواقيت، القبلة، التخزين
    utils.ts            # التطبيع العربي، التنسيق، التواريخ الهجرية
  test/                 # ٤٠ اختباراً (بيانات، عربي، قبلة/صلاة، محرّك الصوت)
```

## الاستماع دون إنترنت

- **تنزيل صريح:** زر سحابة في صفحة السور وقارئ السورة وداخل المشغّل الكامل —
  يُعرض تقدّم التنزيل بنسبة مئوية، وتُحفَّظ النسخة باسم القارئ المختار ساعتها
  (لا اختلاط بين القرّاء).
- **حفظ تلقائي أثناء الاستماع:** أي سورة تشغّلها تُخزَّن في الخلفية
  (يُدار حجمها ولا يُتجاوَز بأي تنزيل آلي شامل) — قابلة للإيقاف من الإعدادات.
- **أولوية التشغيل المحلي:** المشغّل يقرأ من جهازك أولاً فتبدأ التلاوة فورياً
  حتى بلا شبكة، مع شارة «محفوظ — يعمل دون إنترنت»، ويسقط للشبكة تلقائياً
  إن كانت النسخة المحلية تالفة.
- **الإدارة:** الإعدادات ← «الاستماع دون إنترنت»: أحجام الملفات، أسماء
  القرّاء، حذف فردي أو مسح كامل.
- **النص أيضاً:** صفحات السور التي فتحتها تعمل دون اتصال (تُخزَّن بعد أول
  عرض) مع شارة اتصال تظهر أعلى الشاشة عند الانقطاع.

## استكشاف الأخطاء

- **«تعذّر تشغيل التلاوة»**: تحقق من الإنترنت؛ المشغّل يجرّب المصدر الاحتياطي
  تلقائياً ثم يعرض زر إعادة واضحاً (لا يبقى في تحميل أبدي).
- **النص لا يظهر دون اتصال**: السور التي فتحتها سابقاً محفوظة محلياً وتعمل
  دون إنترنت؛ السور الجديدة تحتاج اتصالاً لمرة واحدة.
- **البوصلة لا تدور**: جهازك بلا حساس اتجاه أو الإذن مرفوض — سيظهر وضع
  التدوير اليدوي مع شرح واضح، ويظل اتجاه القبلة المحسوب صحيحاً.
- **لا يُعرض أي حديث أو ذكر بدون مصدر مُخرِج** — لا يُولَّد محتوى ديني آلياً.
